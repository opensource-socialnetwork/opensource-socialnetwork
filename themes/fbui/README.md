# Facebook Style Theme for Open Source Social Network

A clean, high-performance custom theme designed for **Open Source Social Network (OSSN)**. This theme is created to give users a familiar, modern social network experience with optimized layout handling and blazing-fast performance.

### ⚠️ Disclaimer
*This theme is independently developed to provide users with a similar, intuitive social platform experience. It is in no way affiliated with, authorized, maintained, sponsored, or endorsed by Facebook, Meta Platforms, Inc., or any of its subsidiaries.*

### ✨ Key Features

* **Modern UI/UX:** A polished, clean layout designed to maximize user engagement and community interaction.
* **Smart Floating Sidebars:** Custom layout logic ensuring butter-smooth scrolling and responsive sidebar behavior across long feeds.
* **Optimized AJAX Handling:** Seamless background loading and polling interactions without layout shifts or coordinate resets.
* **Fully Responsive:** Adapts flawlessly across desktop browsers, tablets, and mobile viewports.
* **Lightweight & Fast:** Optimized codebase for quick load times and high efficiency on self-hosted environments.
